# HydroTrack

HydroTrack is a Windows desktop application that uses computer vision to automatically detect when a user drinks water.

## Features

- Real-time bottle detection
- Bottle color calibration
- MediaPipe facial landmark tracking
- Adjustable color sensitivity
- Adjustable bottle search range
- Hydration reminders
- Optional reminder sound
- Drink statistics
- Scrollable drink log
- Manual removal of incorrect detections
- Optional detection mask for debugging

## Built With

- Python
- OpenCV
- MediaPipe
- PySide6
